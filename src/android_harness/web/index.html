手机需要 Android 11 或更高版本。中文输入需要安装并启用配套输入法，提交后恢复原键盘。

连接问题怎么处理

没有设备：检查数据线、USB 端口，或使用无线调试。待授权：在手机确认 RSA 弹窗。离线：重新连接。锁屏：由本人解锁。多个设备：明确选择目标。

任务授权的边界

停止后不再开始新步骤；已经提交的操作可能已生效。超出任务的发送、删除、安装和权限变更应单独确认。任务授权约束本工具的受管入口，本机脚本与其他 ADB 客户端仍由你管理。
